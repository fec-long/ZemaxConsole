# ZemaxConsole

ZemaxConsole 是一个面向 Zemax 透镜脚本开发的 Windows 桌面工具，集成 Python 代码编辑、分段运行、ZPL 宏生成和本地 AI 辅助纠错。

用户可以通过 Python 描述透镜结构，在代码框旁与 AI 对话，选中代码获取修复建议，并将生成的 ZPL 宏导入 Zemax 执行。

当前版本：0.2

## 功能

- 代码编辑：打开、保存 Python 文件，支持撤销。
- 分段运行：运行全文、鼠标选区或当前代码段。
- 会话保留：分段运行时保留变量和透镜数据。
- 输出与报错：显示运行输出、异常堆栈及错误行号，保留出错前的输出。
- 运行控制：支持停止并重置，单次运行超过 60 秒自动重置。
- 本地 AI 对话：通过 Ollama 接入模型，解释代码、回答问题和提出修改建议。
- 选区纠错：鼠标选中代码后提交纠错，查看建议并应用到原选区。
- 修改检查：应用前检查整份代码的语法；编辑内容发生变化时拒绝应用旧建议。
- ZPL 导出：生成基础序列球面透镜宏，支持预览和保存。

## 安装与启动

### 启动主程序

下载 ZemaxConsole.exe，保存到本地文件夹后双击启动。

主程序已包含 Python 运行所需组件，无需另外安装 Python。当前交付为 Windows x64 便携程序，未进行数字签名。

### 配置本地 AI

1. 在右侧填写模型名称，默认使用 qwen2.5-coder:7b。
2. 点击“配置模型”并确认。
3. 程序尝试通过 Windows winget 安装 Ollama、启动本地服务并下载模型。
4. 等待出现“模型部署完成”，即可发送问题。

首次配置需要联网。默认 7B 模型下载约 4.7 GB，运行还需要额外内存，响应速度取决于硬件配置。

如果自动安装失败，可从 Ollama 官网手动安装，然后重新配置模型：
https://ollama.com/download/windows

也可以在终端执行：

    ollama pull qwen2.5-coder:7b

资源有限时，可将程序中的模型名称改为 qwen2.5-coder:3b，再下载对应模型。

AI 不可用时，仍可使用代码编辑、运行和 ZPL 导出功能。

## 快速开始

将下面的代码粘贴到左侧编辑区，按 F5 运行：

```python
# %% 定义参数
radius = 50.0
thickness = 5.0
diameter = 25.0

# %% 创建透镜
add_lens(
    radius1=radius,
    radius2=-radius,
    thickness=thickness,
    diameter=diameter,
    glass="N-BK7",
)

add_space(45.0)

# %% 输出结果
print("已生成一片双凸透镜")
print("后表面至像面的距离为 45 mm")
```

运行成功后，在“ZPL 预览”中查看结果，点击“导出 ZPL”保存宏文件。

示例中的 45 mm 是演示像距，未进行自动对焦。

## 运行方式

运行全文（F5）：重置会话，再执行全部代码。
运行选区（F6）：执行鼠标选中的代码，保留会话。
运行当前段（F7）：执行光标所在的 # %% 代码段，保留会话。
停止并重置（按钮）：终止执行，清空变量、模型和导出结果。

使用独立一行的 # %% 分隔代码段：

```python
# %% 第一步
distance = 20.0

# %% 第二步
print(distance)
```

分段执行时，应先运行定义变量的段落。选区执行时，应选择完整语句；循环、条件语句和函数应包含完整代码块。

重复运行建模段会继续添加透镜或累加空气距离。需要重新建模时，使用 F5 或先点击“停止并重置”。

## 选中代码纠错

1. 用鼠标选中需要修改的代码。
2. 可在右侧输入补充要求，例如“修复报错，保留原有变量名”。
3. 点击“选中纠错”。
4. 查看助手的解释和候选 Python 代码。
5. 点击“应用建议”，将修改写入原选区。

应用建议前，程序会检查替换后的整份代码是否通过语法解析。如果请求发出后编辑区已被修改，旧建议不会直接应用，需要重新提交纠错。

应用后会话重置，代码不会自动执行。可使用 Ctrl+Z 撤销，再检查并重新运行。

语法检查通过不代表计算结果或光学设计正确，AI 建议仍需验证。

## 建模接口

所有长度单位均为 mm。

### 添加透镜

```python
add_lens(
    radius1,
    radius2,
    thickness,
    diameter,
    glass="N-BK7",
)
```

radius1：第一面的曲率半径。
radius2：第二面的曲率半径。
thickness：透镜中心厚度。
diameter：透镜几何直径。
glass：目标 Zemax 材料目录中的玻璃名称。

半径为 0 或无穷大表示平面。函数创建两个标准球面，并返回它们的面号。

程序会检查厚度、直径、球面口径以及边缘相交等基础几何条件。

### 添加空气距离

```python
add_space(thickness)
```

增加最后一片透镜之后的空气距离，不创建额外曲面。连续调用会累加距离；最后一段空气距离对应后表面至像面的距离。

### 数学计算

运行环境提供 math：

```python
value = math.sqrt(25)
print(value)
```

## 在 Zemax 中使用

1. 保存当前 Zemax 工作。
2. 新建空白序列系统，初始结构为 OBJ=0、STOP=1、IMA=2。
3. 设置镜头单位为 mm，并确认材料目录包含脚本使用的玻璃。
4. 手动设置系统孔径、视场和波长。
5. 将导出的 ZPL 放入相应宏目录，通过 Zemax 宏菜单运行。
6. 检查镜头数据、布局和分析结果。

程序设置的是曲面半口径，不会自动设置系统入瞳直径、波长或视场。

每次重新执行宏前，应重新建立空白序列系统。宏的面数检查不能证明当前设计为空白，也不能代替模式检查。

## 输出与错误处理

“输出与报错”面板显示 print() 输出和完整异常信息。异常发生前的输出会保留。

执行失败时，前面的代码可能已经改变变量或透镜数据。建议修复后使用 F5 重新运行，避免在不确定的会话状态下继续建模。

导出使用最近成功运行的会话模型。尚未运行的编辑不会自动包含在导出结果中。
